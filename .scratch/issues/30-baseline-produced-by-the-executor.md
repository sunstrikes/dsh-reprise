# 30: 基线由执行器自己跑出来

**What to build:** 分母不再靠外部给：BASELINE 阶段自己提交一次训练、按窗口收指标、冻结成这次运行的分母。README 公布的数字只是旁证，不进事实面。

**Blocked by:** 15, 19

**Status:** ready-for-agent

- [ ] BASELINE 不再是「只读一个 `baseline.json`」：它走与候选相同的提交、等待、采集路径。
- [ ] 基线样本进事实面，形状与候选样本一致（窗口序号 + 起止 + 指标表），否则配对无从谈起。
- [ ] 基线冻结后不再刷新；同一工作区第二次启动读到的是冻结值，不是重跑值。
- [ ] 基线跑不出来（失败、无指标、窗口为空）时判停在工作区层面并说明原因，不是带着空分母继续。
- [ ] 基线作业与候选作业在台账里分得清（避免被当成候选重复派发）。
