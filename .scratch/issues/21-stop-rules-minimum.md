# 21: 判停最小集

**What to build:** 三条判定进代码：指标还没打出来不能判死候选、一有回归就提前杀、超时与窗口数上限变成整个工作区能看见的结论。

**Blocked by:** 20, 30

**Status:** ready-for-agent

- [ ] 最后一个窗口没有有限数值 → 判死该候选，理由写「证据无效」，不等到超时才收场。
- [ ] 逐指标的回归上限：尾部 N 个窗口都越过容差才杀；容差可被一个下限抬高（**只收紧不放宽**）。
- [ ] 超时与窗口数上限提升为工作区级判停结论，而不只是 reject 单个候选。
- [ ] 判停只读平台事实与窗口样本；模型自述既不能延长也不能缩短运行。
- [ ] 三条各有「能失败」的用例，不是只测通过路径。
