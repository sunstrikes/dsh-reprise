## 结论

六条 GET-only exact Fetch 路由挂在宿主已有 HTTP 表面上，34 条测试。四视图 + 增量游标 + 只读（readOnly 句柄写入抛错、全路由巡览后事实字节一致）+ 与 `dump` 逐字段一致（失败原文逐字比对）。

**游标不是裸整数。** 事件身份是二元组 `(candidate_id, local_seq)`，后建候选从 1 重新开始，裸整数会静默漏掉它的头几条事实。改成 `<wall_clock_ms>:<candidate_id>:<local_seq>`，并有一条专门为此写的测试。spec 已改。

**未验**：真宿主的 cookie、`--dsw-alias-*` 是否能到达这个独立页面（判断达得到才怪，用户会看到系统色回退）、非 owner Peer 的 403——已列成 `packages/ui/README.md` 的冒烟清单。
