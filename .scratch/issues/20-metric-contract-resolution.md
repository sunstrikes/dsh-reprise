# 20: 指标契约分辨率

**What to build:** 契约要能说清「哪个指标说了算、多大的差别才算差别、看窗口均值还是末窗」，这样判停、前沿、准入三处读的是同一份东西。

**Blocked by:** 19

**Status:** ready-for-agent

- [ ] 两种角色：主指标与护栏指标，契约能表达哪个是主。
- [ ] 最小有效幅度：有默认值，且能按指标名逐个覆盖。
- [ ] 窗口口径：均值窗 / 末窗，可按指标名选。
- [ ] 契约缺失或自相矛盾时，判停、前沿、准入三处一律说「没有契约」，各自不许猜。
- [ ] 明确写下延后项：「这个指标在当前数据里到底测不测得到」的资格判定，本票不做。
