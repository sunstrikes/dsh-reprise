# 16: 集群作业台账

**What to build:** 集群是共享的、GPU 还不隔离，所以「我们提交了哪些作业、哪些该收掉」必须有确定答案，而不是去网页上肉眼找。

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] 每个作业带可识别标记（候选 id + 轮次），从作业列表里认得出自己的。
- [ ] 孤儿作业（台账里没有、集群上还在）能被列出；清理必须是显式动作，不能自动。
- [ ] GPU 排他二选一并写进配置校验：同一时刻只允许一个训练作业，或提交时自己写 `CUDA_VISIBLE_DEVICES`。
- [ ] 被外部停掉（canceled）与训练失败（failed）在台账里是两件事。
