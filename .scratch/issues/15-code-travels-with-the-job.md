# 15: 候选代码随作业走

**What to build:** 一个候选的 worktree 改完之后，能在集群上被原样跑起来，中间不需要人搬文件。

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] 提交前把候选 worktree 打成归档（排除工作区自己的事实面目录），随作业送达节点。
- [ ] 作业在解包后的目录里启动训练，读到的就是候选改过的那份配置。
- [ ] 「改了哪些文件」仍以 runner 的 git diff 为准：打包前记一次、解包后核一次，不一致判 conflict 而不是继续。
- [ ] 归档过大、或候选含未跟踪文件时，给出明确结论而不是硬跑。
- [ ] 同一个 submission_id 重复提交不会产生第二份作业。
